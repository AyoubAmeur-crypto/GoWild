# goWild Firebase Functions v2 (Python 3.12)

Managed callable backend in `europe-west1`. Deploy `testConnection` first, then user-data callables and the chosen sandbox supplier callable. The runtime uses its Firebase-managed service account; do not download a private key.

See [deployment and verification](../README/FIREBASE_SETUP.md), [public configuration](../README/FIREBASE_PUBLIC_CONFIG.md), and [secret names](../README/FIREBASE_SECRETS.md).
