## 2. Typography
- **Display**: Montserrat Medium (32pt), Bold (40pt).
- **Headings**: Montserrat SemiBold (18pt, 24pt).
- **Body & Labels**:
  - Regular: 12pt, 14pt (CircularXX / System Sans).
  - Medium / Book: 10pt, 12pt, 13pt.
  - Bold: 14pt, 16pt.

## 3. Radii & Shadows
- **Card Large**: 24pt
- **Card Medium**: 16pt
- **Pill / Chip**: 33pt / 59pt (Fully rounded)
- **Buttons**: 16pt
- **Popular Card Shadow**: `0px 11px 26px rgba(36, 129, 216, 0.29)`
- **Recommended Card Shadow**: `0px 4px 20px rgba(151, 160, 178, 0.17)`
- **CTA Button Shadow**: `0px 6px 19px rgba(0, 56, 255, 0.24)`
